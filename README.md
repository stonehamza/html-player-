# HTML TV Launcher — Full Control v3

هذه النسخة تعدّل طريقة تشغيل الملف المختار:
- لا تستخدم `sandbox` على iframe حتى لا تمنع بعض واجهات الألعاب وميزات المتصفح.
- تُحمّل الصفحة كـ Blob URL بدل `srcdoc`.
- تمنح الإطار التركيز بعد التحميل لتصل إليه لوحة المفاتيح.
- تسمح بملء الشاشة وGamepad وPointer Lock واللمس بحسب دعم المتصفح.
- زر ملء الشاشة وزر العودة للقائمة.

## النشر
ارفع كل الملفات مباشرة إلى جذر GitHub Pages. افتح الرابط مرة بالإنترنت وانتظر رسالة اكتمال التخزين.

## ملاحظات
- اختر ملفات HTML التي تثق بها فقط؛ إزالة sandbox تحسن التوافق لكنها تعطي الملف صلاحيات أوسع ضمن أصل الموقع.
- Blob URL يحسن التعامل مع صفحة HTML الواحدة، لكنه لا يجعل ملفات الموارد الخارجية المفقودة متاحة تلقائيًا. ألعاب HTML التي تحتاج مجلدات صور/صوت/JS/CSS بجانب الملف تحتاج آلية استيراد مجلد أو ZIP، وليست مدعومة في هذا الإصدار.
- اضغط داخل اللعبة مرة بعد فتحها لتفعيل إدخال لوحة المفاتيح/الماوس. Pointer Lock وFullscreen يحتاجان عادةً تفاعلًا مباشرًا من المستخدم.
- دعم منتقي الملفات والماوس/الكيبورد يختلف حسب متصفح Google TV.
